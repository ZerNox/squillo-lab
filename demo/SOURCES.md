# Real-voice demo clips

From VocalSet 1.1: J. Wilkins, P. Seetharaman, A. Wahl and B. Pardo (2018),
*VocalSet: A Singing Voice Dataset*, ISMIR 2018. Zenodo record 1442513,
doi:10.5281/zenodo.1442513. Licence: CC BY 4.0. Changes: leading silence
removed, cut to at most 20 s, mono 80 kbit/s MP3.

| File | VocalSet member |
| :--- | :--- |
| `f2_straight.mp3`, `f2_breathy.mp3`, `f2_vocal_fry.mp3`, `f2_belt.mp3`, `f2_vibrato.mp3` | `FULL/female2/scales/<technique>/f2_scales_<technique>_a.wav` |
| `f2_caro_straight.mp3`, `f2_caro_vibrato.mp3` | `FULL/female2/excerpts/<technique>/f2_caro_<technique>.wav` |
| `m2_straight.mp3`, `m2_breathy.mp3`, `m2_vocal_fry.mp3`, `m2_belt.mp3`, `m2_vibrato.mp3` | `FULL/male2/scales/<technique>/m2_scales_<technique>_a.wav` |
| `m2_caro_straight.mp3`, `m2_caro_vibrato.mp3` | `FULL/male2/excerpts/<technique>/m2_caro_<technique>.wav` |

Each scale group is the same singer on the same scale and vowel (/a/) with
one technique changed, so the clips differ only in the technique. "Caro mio
ben" is Giuseppe Giordani's 18th-century aria (public domain).
